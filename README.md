# Dimensões Teóricas da Agência Discente na Pós-Graduação Internacional: Dados e Materiais Suplementares

Este repositório reúne os dados suplementares, protocolos analíticos e materiais metodológicos da pesquisa intitulada:

> **"Dimensões Teóricas da Agência Discente: Fundamentos Seminais e Ações Proativas na Adaptação Institucional"**

## Conteúdo do Repositório

- `data/`: Planilhas com os 100 documentos analisados ($N = 100$), incluindo identificação bibliográfica, enquadramento tipológico e códigos analíticos.
- `protocolos/`: Documento completo do **Protocolo de Extração Analítica de Dados (PEAD-Agência)**.
- `apendices/`: Tabela detalhada dos estudos mapeados e modelos de notas analíticas (*memos*).
